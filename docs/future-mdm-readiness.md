# Future MDM readiness

The framework remains generic. Custom MDM models, workflows, approvals, OPCO
relationships, external ERP integrations and custom validation are future
integration considerations, not confirmed client requirements or implemented
features. No client-specific behavior is currently implemented.

Before defining the real migration scope, obtain:

- Original Odoo 12 source and custom modules.
- Database **and filestore** backups and installed module inventory.
- Technical documentation, API specifications and business workflows.
- Confirmed production target version and hosting architecture.
- Data volumes and user/security configuration.
- Client acceptance criteria and approved scope of work.
- Migration, cutover and rollback plans.

The stated future go-live is 2027-01-01. No enterprise readiness or schedule
feasibility has been demonstrated. Chatter preservation, recovery after target
restore and production performance require separate measured evidence.
